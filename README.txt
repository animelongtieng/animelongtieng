AnimeLongTieng - source project

Cau truc:
- index.html: giao dien HTML
- style.css: giao dien CSS
- app.js: chuc nang JavaScript (tim kiem, loc, chi tiet, trinh phat)
- data/anime.js: danh sach du lieu anime/phim mau

Cach chay: mo index.html bang trinh duyet.
Them/sua phim: chinh mang window.ANIME_DATA trong data/anime.js.
Luu y: ban nay la frontend demo; du lieu phia trinh duyet duoc luu bang localStorage, chua co server/database dung chung.
